POLYMATH DISPLAY (headings font)
================================
Polymath Display is a commercial typeface by OH no Type (https://ohnotype.co/fonts/polymath).
The free "Demo" version is only for testing; a licence is required before the live website
uses it. The site falls back to Urbanist until the font is available.

PREVIEW ON YOUR OWN COMPUTER (allowed for testing)
  Install the Demo font on your Mac/PC (double-click the .otf/.ttf, click Install), then open
  index.html. The site picks up the installed font automatically. Visitors will NOT see it.

GO LIVE - choose ONE:
  A) Buy a WEBFONT licence from OH no Type, then put these files in this folder
     (names must match exactly; include the weights you need):
        PolymathDisplay-Light.woff2      (300)
        PolymathDisplay-Regular.woff2    (400)
        PolymathDisplay-Medium.woff2     (500)   <- main heading weight
        PolymathDisplay-Semibold.woff2   (600)
        PolymathDisplay-Bold.woff2       (700)
     If you receive .otf/.ttf only, convert them to .woff2 (e.g. with an online converter
     that your licence allows, or the "woff2" command-line tool).

  B) Adobe Fonts (included with Creative Cloud): add Polymath Display to a Web Project,
     copy its <link rel="stylesheet" href="https://use.typekit.net/xxxxxxx.css"> line and paste it
     into the <head> of every .html page, just above the line that loads assets/css/site.css.
     The site already looks for the Adobe family name "polymath-display".
